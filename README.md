# Elite Taller Mecánico

Sitio web estático para GitHub Pages.

## Estructura
- index.html
- styles.css
- scripts.js
- img/

## Publicación
1. Sube este proyecto a GitHub.
2. Entra a Settings > Pages.
3. Selecciona la rama principal como fuente.
4. Guarda y espera a que se publique.

La web estará disponible en:
https://<tu-usuario>.github.io/<nombre-del-repositorio>/
